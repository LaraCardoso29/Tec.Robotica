# Site
 Mitos e Verdades sobre o Daltonismo

Trabalho Escolar de Robótica (Maria Laura), Física Tec. ( Jeane) e  Programação (Buiu)
 Lara Cardoso Alvino

📌 Sobre o Projeto

Este projeto consiste em uma aplicação web interativa em estilo cartões 3D flutuantes (Flash cards) que aborda os principais mitos e verdades sobre o daltonismo. O estudo conecta conceitos científicos aprendidos nas aulas de:

💡 Física: Teoria das cores, espectro luminoso e percepção visual, olho humano.

🤖 Robótica: Montagem e programação de circuitos Arduino utilizando LED RGB, projeto Arco-iris e potenciômetros para síntese de cores.

💻  Programação: Desenvolvimento web com HTML5, CSS3 .

🎨 Funcionalidades

Cartões Interativos 3D: Clique em qualquer cartão para revelar se a afirmação é MITO ou VERDADE.

Design Temático: Paleta de cores em tons de rosa e violeta escuro para reforçar o contraste e a percepção cromática.
